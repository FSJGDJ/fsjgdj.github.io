## 第二轮美化方案（docs/blog-beautify-plan.md，与桌面《博客美化方案.md》同一份）可行性评估

未改任何代码，只做核验。结论要点（留给后续落地参考）：

- 方案与站点基线（毛玻璃 + 背景图 + 靛蓝 + 衬线标题 + 正文不套卡片）不冲突，可执行；工作量估算大体靠谱。
- 已确认两处硬伤属实：① `--font-serif` 栈在 Windows 上实际回退宋体；② `Layout.astro` 的 head 只有 title/favicon/rss，无 description/OG。
- 已实测：Shiki 输出 `<pre class="astro-code ..." data-language="python">` 且每行是 `<span class="line">` → B4 语言徽章、B5 行号零成本可行；首个代码块是 `plaintext`，徽章需过滤。
- 需修正的估算：A2 `text-autospace` Chromium 支持存疑（caniuse/web-features 标不支持，MDN 标 Chrome 140+）；D6 View Transitions 不是"小"，[slug].astro 里 TOC/灯箱/复制按钮三段 IIFE 需全部改 `astro:page-load`；A1 有 FOUT 跳字与子集产物须入库的隐藏成本；D8 背景图在 Layout 的 CSS `url()` 里，astro:assets 不能直接用。
- A1 字体选型（思源宋体 = 延续杂志感 vs 霞鹜文楷 = 楷体手账感）属气质替换，必须用户拍板。
- 内容量仅 6 篇、全文 1 张表格 0 公式 0 mermaid → C4 KaTeX/Mermaid、D2 自动 OG 图、D4 Pagefind、D5 Giscus、C2 相关文章建议推迟到内容量上来再做。
- 顺手发现：`--font-sans` 变量在 Layout 中未定义但 [slug].astro:577 用了；站名硬编码 "我的博客"（title/footer/rss），config.ts 无 siteName 字段。

## 第一轮实施（用户选「霞鹜文楷 + 修订版第一轮」范围）

已落地并 `astro build` 通过（20 页），dev server 在 http://127.0.0.1:4321/ 供预览。

- **A1 字体（换方案）**：cn-font-split 路线作废——GitHub releases 在本机不可达，拿不到源字体 TTF。改用 `lxgw-wenkai-lite-webfont@1.7.0` 这个**已按 unicode-range 切好的** npm 包，`scripts/setup-fonts.mjs` 下载 97 个 woff2（3.86MB）到 `public/fonts/lxgw/` 并生成本地 `lxgw.css`（改写 url 路径 + 注明来源与 OFL 授权）。实测单页只命中 2~14 个分片。标题字重 600→500，避免 faux-bold。
- **D1 meta/OG**：Layout 增 description/canonical/author/robots/theme-color + 完整 OG 与 twitter:card，文章页经 `<slot name="head" />` 注入 `article:published_time`、`article:tag`；og:image 暂用 bg.jpg（1920×1280）。新增 `src/pages/404.astro`（D3，带 noindex + 最近三篇）。`config.ts` 加 siteName / description，站名不再硬编码。
- **B1/B2/B3**：Layout 里 `::-webkit-scrollbar` + `scrollbar-width: thin` 细圆角滚动条（需 `:global()` 包裹，scoped 会让伪元素选择器失效）、`::selection` 用 accent 半透明、顶部 2px 阅读进度条（放在 glass-panel 外，rAF 节流，只在文章页开）。
- **C1/C3**：文章页加上一篇/下一篇（两列 grid，标题最多两行）；新增 `/tags/[tag]` 落地页（12 个，中文标签路由正常），TagCloud 的标签由 span 改为链接，文章页标签也可点。
- **B6**：正文表格改 `display:block; overflow-x:auto`，窄屏不再挤爆。
- **A2**：`text-autospace: normal` 加在 body（Chromium 目前仍不支持，属渐进增强）。
- 顺手修：补上 `--font-sans` 变量定义；导航"目录"改"归档"（与文章 TOC 概念撞名）。
- 待确认项：motto 仍为空（是否填文案/加打字机未定）；真·Bold 字重未装（会让仓库再涨 3.9MB）。
