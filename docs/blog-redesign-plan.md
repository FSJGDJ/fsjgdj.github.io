# 博客界面美化方案

> 目标：在现有极简风格基础上，分两阶段升级界面。
> 阶段一先补齐硬伤（代码块、目录、个人标识、暗色切换），阶段二再向"杂志感极简"靠拢（去卡片化、排版精修）。
> 参考方向：AstroPaper / Bear Blog 的排版理念、Fuwari 的组件完成度——只借鉴思路，不照搬主题。

---

## 一、现状与问题

| 模块 | 现状 | 问题 |
| --- | --- | --- |
| Hero 区 | 渐变文字标题 + 一句简介 | 无头像、无昵称、无个人定位，访客不知道博主是谁 |
| 文章列表 | 白底卡片，日期+标题+摘要+阅读全文 | 无标签、无阅读时长，信息层级单一 |
| 文章页 | 卡片容器包裹正文 | 长文无目录；代码块无样式（仅行内 code 有）；无复制按钮 |
| 导航 | 🚀 Logo + 首页 + GitHub | 无手动明暗切换，只能跟随系统 |
| 页脚 | 版权 + Astro 链接 | 单薄，无 RSS / 邮箱 / GitHub 入口 |
| 内容组织 | 4 篇文章平铺 | 无标签/分类体系，内容多起来后会失控 |

---

## 二、阶段一：精修（补硬伤）

原则：不改骨架，逐项升级，每项改动独立可回退。

### 1. 个人标识（Hero 区升级）

- Hero 区加入**圆形头像**（80px）+ 昵称 + 一句话定位（如"信息安全在读 · Windows 内核与系统分析"）
- 标题渐变保留但**降低饱和度**：由 `#6366f1 → #ec4899` 改为 `#4f46e5 → #7c3aed`（紫蓝单色系），减少"模板感"
- 头像下方放一排社交图标（GitHub / 邮箱 / RSS），用 SVG 图标而非 emoji

### 2. 代码块样式 + 复制按钮

- 代码块使用深色底（亮暗模式统一用 `#0d1117` 或 GitHub Dark），圆角 10px，内边距 1rem
- 等宽字体栈：`"JetBrains Mono", "Cascadia Code", Consolas, monospace`
- 右上角悬浮"复制"按钮，点击后变为"已复制 ✓"，1.5 秒后还原
- 行内 code 样式保留现有逻辑，仅微调圆角和内边距

### 3. 文章页目录（TOC）

- 从 Markdown 的 `headings` 自动生成 h2/h3 目录
- 宽屏（>1100px）：目录固定在正文右侧，`position: sticky`，当前阅读章节高亮
- 窄屏：目录折叠在标题下方，可展开

### 4. 手动明暗切换

- 导航栏右侧加太阳/月亮图标按钮
- 用 `data-theme` 属性 + `localStorage` 记忆用户选择，默认跟随系统
- 在 `<head>` 内联一段小脚本防止刷新时的主题闪烁（FOUC）

### 5. 文章元信息

- 文章 frontmatter 增加 `tags` 字段（如 `["KMDF", "驱动开发"]`）
- 列表卡片与文章页标题下方显示标签（小胶囊样式）
- 按字数估算阅读时长（中文约 400 字/分钟），显示"约 X 分钟"

### 6. 页脚与 RSS

- 页脚改为一行式：`© 2026 昵称 · GitHub · 邮箱 · RSS · Powered by Astro`
- 接入 `@astrojs/rss`，生成 `/rss.xml`

**阶段一涉及的文件：**

| 文件 | 改动 |
| --- | --- |
| `src/layouts/Layout.astro` | 主题切换脚本与按钮、页脚重写、新增 CSS 变量 |
| `src/pages/index.astro` | Hero 区（头像+定位+图标）、卡片加标签和阅读时长 |
| `src/pages/blog/[slug].astro` | TOC、代码块样式、复制按钮、标签展示 |
| `src/content/blog/*.md` | frontmatter 补 `tags` 字段 |
| `package.json` | 新增 `@astrojs/rss` 依赖 |
| 新增 `src/components/` | ThemeToggle、TOC、CodeCopy 等小组件 |

## 三、阶段二：向"杂志感极简"靠拢

原则：阶段一稳定运行后，再做视觉减法。此阶段**只动样式，不动结构**。

### 1. 去卡片化

- 文章列表从"白底卡片"改为**纯排版列表**：去掉边框和背景，条目之间用细分割线或纯留白分隔
- 悬停效果从"上浮+阴影"改为"标题变色 + 左侧出现短竖线标记"，更克制

### 2. 排版精修

- 文章页正文**去掉卡片容器**，直接排版在背景色上，让长文像一页纸
- 标题字体引入衬线（如 `"Source Han Serif SC", "Noto Serif SC", serif`），正文保持无衬线，形成中西文混排的杂志感
- 行宽从 720px 微调到 680px（正文最优行长），标题与正文的字号比例重新校准（h1 2rem / h2 1.5rem / 正文 1rem，行高 1.75）
- 段间距、列表间距、引用块样式统一走一套"8px 基准"的间距体系

### 3. 配色收敛

- 主色从靛蓝收敛为**低饱和蓝紫**（亮 `#4f46e5` / 暗 `#a5b4fc`），全站只用这一个强调色
- 背景灰阶微调：亮色 `#fafafa`、暗色 `#111114`，减少纯白/纯黑的生硬对比

### 4. 细节动效（可选，克制使用）

- 接入 Astro View Transitions，页面切换时内容淡入
- 仅给标题和链接加过渡，不给容器加位移类动效

---

## 四、明确不做的

- **不做左侧栏资料卡**（Fuwari 式）：文章量只有 4 篇，侧栏会显得空；等文章到 15+ 篇再考虑
- **不做封面图体系**：技术文章找封面图成本高、风格难统一，纯文字列表反而干净
- **不做评论系统、访问统计**：现阶段无必要
- **不整站换主题模板**：保留现有代码结构，渐进式改造，每一步可回退

---

## 五、验收标准

- [ ] 阶段一完成后：代码块有深色样式和复制按钮；长文右侧有可用目录；可手动切换明暗且刷新不闪烁；每篇文章有标签和阅读时长；`/rss.xml` 可访问
- [ ] 阶段二完成后：列表与文章页无卡片边框；标题为衬线字体；全站仅一个强调色；Lighthouse 性能分不低于现状
- [ ] 两阶段各自独立提交，可随时回退到任一阶段

---

## 六、建议执行顺序

1. 代码块样式 + 复制按钮（技术博客收益最大）
2. 手动明暗切换
3. 个人标识（头像 + 定位 + 图标）
4. 标签 + 阅读时长
5. 文章页目录
6. 页脚 + RSS
7. （以上验收后）阶段二整体视觉减法

## 七、阶段三：全屏背景图与毛玻璃（2026-09-20 追加）

> 参考 diary.fulitower.art 的呈现质感（照片背景 + 半透明内容层）。
> **明确排除**：不加入该站风格的鼠标拖拽动画与页面花瓣特效。

### 效果定义

- **背景**：云海山峦照片（`public/images/bg.jpg`，约 314KB）以 `position: fixed + cover` 铺满全屏，滚动时固定不动
- **可读性遮罩**：照片上叠一层半透明纱——亮色模式蒙白纱 `rgba(250,250,250,0.45)`，暗色模式蒙深纱 `rgba(17,17,20,0.55)`，跟随明暗切换，保证文字可读又不盖死照片
- **内容层**：全站正文包进一张"毛玻璃纸"（`.glass-panel`）——半透明底（亮 `rgba(255,255,255,0.72)` / 暗 `rgba(23,26,33,0.74)`）+ `backdrop-filter: blur(16px)` + 16px 圆角 + 细边框 + 柔和投影；窄屏降为 12px 圆角并收窄内边距
- **导航栏**：sticky 毛玻璃加深（blur 14px），底色改用半透明 card 色
- **页脚**：同样加半透明底 + blur，与面板呼应
- **文章页桌面端目录**：悬浮于照片之上，独立加毛玻璃底、圆角与投影，保证可读

### 涉及文件

| 文件 | 改动 |
| --- | --- |
| `public/images/bg.jpg` | 新增背景图（由用户提供） |
| `src/layouts/Layout.astro` | `--card`/`--border`/`--muted` 改半透明体系；`body::before` 背景图 + `body::after` 遮罩；`.glass-panel` 包裹 slot；header/footer 毛玻璃 |
| `src/pages/blog/[slug].astro` | `.toc-desktop` 加毛玻璃底 |

### 明确不做（对应参考站）

- 鼠标拖拽视差/拖拽动画
- 页面飘落花瓣等粒子特效

### 验收标准（阶段三）

- [ ] 背景图全屏固定，明暗两种模式均切换正常
- [ ] 正文、导航、页脚、目录均可读，无文字压在照片上直接看不清的区域
- [ ] 无拖拽动画与花瓣特效
- [ ] 构建通过，移动端内边距收敛正常

## 八、阶段四：首页间距加宽与进场动画（2026-09-20 追加）

> 继续参考 diary.fulitower.art：其文章条目间距很大，进场动画为 `fadeInUp`（从下方上浮、逐条错开）。只借鉴这两个点，不照抄其余。

### 效果定义

- **显示区域加宽**：首页容器从 680px 加宽到 **780px**（`Layout` 新增 `wide` 属性 → `.container-wide`，仅首页启用；文章页保持 680px 最优行长不变）
- **条目间距加大**：首页列表每条上下内边距由 1.5rem 加到 **2rem**；悬停竖线改为随内容全高（`top/bottom: 2rem`），更稳不跑位
- **进场动画（fadeInUp 风格）**：
  - 首屏 Hero 与每条文章以"上浮 26px + 淡入"进场，时长 0.7s，缓动 `cubic-bezier(0.22,0.61,0.36,1)`
  - 条目按序错开：每条延迟 90ms（最多错开 8 条），模拟逐条浮现
  - 用 `IntersectionObserver` 触发：首屏立即逐条进场，滚动到下方时再进场，进入后即停止观察
  - **可访问性**：`prefers-reduced-motion: reduce` 时禁用动画；JS 不可用时（无 `html.js` 标记）内容直接可见，不会白屏

### 涉及文件

| 文件 | 改动 |
| --- | --- |
| `src/layouts/Layout.astro` | `Props` 加 `wide`；`main` 用 `class:list` 切换 `.container-wide`（780px） |
| `src/pages/index.astro` | `wide` 启用；条目内边距 2rem；`.reveal`/`.visible` 动画样式；`IntersectionObserver` 脚本 + 逐条 `transition-delay` |

### 明确不做（对应参考站）

- 不做 `translateY(200%)` 那样的大位移（过于剧烈），收敛为 26px 的克制上浮
- 不做拖拽动画、花瓣特效（延续阶段三的排除项）

### 验收标准（阶段四）

- [ ] 首页明显比文章页宽，视觉重心在列表
- [ ] 打开首页时 Hero 与文章逐条上浮进场，滚动加载时同样触发
- [ ] 关闭 JS 或系统开启"减弱动态效果"时，内容直接可见、无动画
- [ ] 构建通过

### 修订（同日，按用户截图反馈）

用户提供参考站截图：两篇文章之间要有**能露出背景的空隙**，即"每篇文章一张独立卡片"而非连续列表。据此调整：

- **首页去掉整张毛玻璃面板**（`Layout` 新增 `panel` 属性，首页传 `panel={false}`），Hero 与卡片直接浮在照片上
- **每篇文章一张独立毛玻璃卡片**：半透明底 + blur + 14px 圆角 + 投影；卡片之间 `gap: 1.6rem`，空隙直接露出背景照片
- 悬停改为卡片整体反馈：轻微上浮 3px + 阴影加深 + 边框染色（标题变色保留），原先的左侧竖线随列表形态一并移除
- 目录页、文章页保持整张毛玻璃面板不变（`panel` 默认开启）

## 九、阶段五：首屏 Landing（2026-09-20 追加）

> 参考截图（ttdr 风格）：进入站点先看到整屏照片 + 居中头像/站名/标语的 Landing 画面，向下滚动才显示文章列表。

### 效果定义

- **整屏首屏**：`.landing` 占满视口（`min-height: calc(100svh - 10rem)`），内容垂直水平居中：头像（96px）、站名、一句话定位、社交图标
- **大字标语位**：`config.ts` 新增 `motto` 字段（衬线大号字，1.5rem），填内容即显示在定位语下方，留空不显示——对应参考图的书法标语位
- **下滑箭头**：首屏底部居中的下箭头，2.2s 循环上下浮动；点击平滑滚动到文章区（`scroll-behavior: smooth`）
- **文章区**：`#posts` 锚点，`scroll-margin-top` 预留 sticky 头部高度；文章卡片沿用阶段四的独立毛玻璃卡片与逐条进场动画
- **可访问性**：`prefers-reduced-motion` 下箭头动画与平滑滚动均禁用

### 涉及文件

| 文件 | 改动 |
| --- | --- |
| `src/config.ts` | 新增 `motto` 字段（由用户自行填写） |
| `src/pages/index.astro` | hero 改 `.landing` 整屏居中；新增下滑箭头与 `#posts` 文章区 |
| `src/layouts/Layout.astro` | 全局 `html { scroll-behavior: smooth }`（含 reduced-motion 降级） |

### 验收标准（阶段五）

- [ ] 进入首页先见整屏 Landing，照片铺满、内容居中
- [ ] 点箭头或向下滚动后文章卡片出现，进场动画正常
- [ ] reduced-motion 下无浮动与平滑滚动
- [ ] 构建通过
